# MicroBlog Architecture

## Stack

- SvelteKit
- TypeScript
- Tailwind CSS
- Supabase Auth
- Supabase Postgres
- Supabase Row Level Security
- Vitest
- Playwright

## Week 1 Scope

The first version supports:

- Account registration
- Account login
- Private user profile
- Private 100-word posts
- Public, private, and followers-only 100-word posts
- Combined signed-in feed
- Public profile pages
- Profile editing
- Approved follow requests
- Delete own posts

## Deferred Features

- Image attachments
- Location tagging
- Reactions
- Comments
- Chat
- Notifications
- Internationalization
- Storybook
