# MicroBlog Architecture

## Stack

- SvelteKit
- TypeScript
- Tailwind CSS
- Supabase Auth
- Supabase Postgres
- Supabase Row Level Security
- Vitest
- Playwright

## Week 1 Scope

The first version supports:

- Account registration
- Account login
- Private user profile
- Private 100-word posts
- Personal feed
- Delete own posts

## Deferred Features

- Image attachments
- Location tagging
- Public posts
- Followers
- Reactions
- Comments
- Chat
- Notifications
- Internationalization
- Storybook
